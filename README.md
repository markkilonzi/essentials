# nyumbani/essentials

The opinionated foundation of the Nyumbani ecosystem. It holds what every internal app shares, so that all of them look and are structured the same way:

1. Helpers (`src/Utils`)
2. Service classes (`src/Services`)
3. UIs (`resources/views`, `resources/js`, `resources/css`)
4. Packages (the Nyumbani packages it standardises)
5. AI skills and rules (`resources/boost`)
